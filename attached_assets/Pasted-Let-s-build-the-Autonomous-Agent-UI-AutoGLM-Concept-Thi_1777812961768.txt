Let's build the **"Autonomous Agent UI" (AutoGLM Concept)**. This feature will visualize the AI's step-by-step reasoning and interaction with the Android UI (using Accessibility Services under the hood later).

Please implement the following with zero placeholders and maintain our Pro-Dark aesthetic:

### 1. Agent Service (`services/AutonomousAgent.ts`)
Create a service to simulate the AI's "Reason & Act" loop:
- `executeTask(prompt, onStepUpdate)`: An async function that takes a user prompt (e.g., "Optimize system and launch PUBG") and emits a sequence of steps to the `onStepUpdate` callback.
- **The Simulated Steps Sequence:**
  1. `{ status: 'active', type: 'thought', text: 'Analyzing intent...' }` (Delay 800ms)
  2. `{ status: 'active', type: 'vision', text: 'Requesting UI Hierarchy (Accessibility Node Info)...' }` (Delay 1000ms)
  3. `{ status: 'active', type: 'action', text: 'Executing System Kernel Drop...' }` -> (Here, call `RootShell.forceDropCaches()` in the background to make it real!).
  4. `{ status: 'active', type: 'vision', text: 'Locating target app icon...' }` (Delay 800ms)
  5. `{ status: 'success', type: 'action', text: 'Task Complete: Game launched.' }`

### 2. UI: Autonomous Agent Screen (`app/agent.tsx`)
Create a dedicated screen for giving complex tasks to the AI:
- **Header:** "Nabd Autonomous Agent" with a robot/cpu icon.
- **Input Area:** A prominent text input asking "What do you want me to do?" and a "Start Agent" button.
- **The Execution Stepper (Live View):** When a task starts, display a vertical timeline of the steps generated by the service.
  - **Styling:** 
    - Active steps should have a glowing cyan/blue border or text to indicate "Thinking/Scanning".
    - Completed steps should turn muted green with a checkmark.
    - Add a small pulsing "radar" or "eye" icon when the `vision` step is active to simulate screen reading.
- **Mini Terminal:** Embed a tiny, read-only 3-line version of our `LiveTerminal` at the very bottom of this screen so the user can see the shell commands being triggered by the Agent in real-time.

### 3. Navigation
Add this screen to the bottom tab bar (or replace the 'Cache' tab if space is needed) using a `cpu` or `target` Feather icon.

This must feel like a live, intelligent Copilot taking control of the phone.
